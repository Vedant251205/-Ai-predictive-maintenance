What must change before production use

  • Replace the development secret key and rotate the seeded demo accounts
  • Serve through a production WSGI server behind TLS, not the Flask development server
  • Move from SQLite to a networked database if more than one process will write
  • Retrain on real run-to-failure data; the current model learned from synthetic hazards
  • Add token authentication before any machine-to-machine API use

What already transfers unchanged

  • The full service and blueprint structure
  • Health banding, RUL heuristic and the P1-P5 priority engine
  • Alerting, acknowledgement and the audit trail
  • Every dashboard, chart and JSON endpoint
  • Kiln availability analytics, which only needs a real export
